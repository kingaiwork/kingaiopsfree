# KINGAI OPS · 中文说明

[English README](README.md)

**服务器 · Edge · IoT 的受治理运维平台**

KINGAI OPS 是 KING AI 主生态的基础设施运维产品。这个仓库是公开发行、安装、升级和文档渠道，**不是私有核心源码仓**。

## 产品理念

KINGAI OPS 围绕一条清晰的运维闭环设计：

**观察 → 理解 → 审批 → 执行 → 验证 → 审计**

目标是减少日常服务器运维的复杂度，同时避免把高权限操作默认交给不受限制的自动化。

## 适用场景

- VPS / 云服务器 / 独立服务器；
- 开发者和小型服务器 Fleet；
- Edge 网关与轻量设备；
- 支持条件满足时的 IoT / OpenWrt 类设备；
- MSP、企业基础设施和未来更大规模的受治理运维。

## 公开产品方向

- 系统健康和资源状态；
- 服务、容器、网站、数据库和网络可视化；
- 安全状态与配置漂移；
- 本地优先控制；
- 安全升级与回滚；
- Fleet 协同方向；
- 策略、审批、审计与未来更丰富的自动化。
